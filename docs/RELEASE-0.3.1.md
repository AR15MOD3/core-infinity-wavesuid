# 0.3.1 更新说明

0.3.2 新增插件自带页面与账号管理模块，见 [页面接入与分发](PAGE.md)。以下为 0.3.1 的历史发布范围。

相对仓库 0.2.3：

- 共享安装，独立 Bot 配置/数据/进程；实例认证、生命周期 guard 与自有子进程收尾。
- 长命令任务化，及时返回已有回执；通过任务编号和游标读取后续，不重复执行登录等副作用。
- 网页登录入口、进度及结果通知接线；通知使用宿主冻结的用户与会话归属。
- 帮助目录精简回执、公开帮助缓存及 PNG 缓存；不在工具内固定人格台词或直接发送 QQ。
- 运行资源隔离、日志脱敏、迁移幂等和服务工作所有权改进。
- 安装器显式下载授权、计划模式、外置版本目录与既有配置保留。

## Core 兼容条件

服务使用 Python 3.11–3.13；收尾证据使用 Python 3.11 的异常接口，不能在 3.10 上运行。

需要正式 Infinity API 1、botScope=1 宿主，并具备：

- bot_id、pluginSettingsBot、pluginConfigPath、pluginDataDir、生命周期 guard。
- telyincore.async_tools 的 OwnedBlockingIO、WorkOwner、current_invocation。
- 正式调用上下文、active_events，以及网页登录结果的系统钩子/通知接线（适用时）。

不能只看 API 数字判断所有新接线已具备。旧 Core 不应通过伪造字段或取消 guard 启动。
当前没有可证明覆盖全部这些能力的最低公开 Core 版本号；发布与安装前须按上述能力验收。
共享 Core 原生账号页另行发布，不随该插件仓库自动升级；详见 SERVICE.md。

## 验证范围

仓库中的离线测试仅使用合成数据和模拟工作，不登录、不发 QQ、不启动生产 Bot。
部署实例已有用户确认的绑定、网页登录及部分私聊/群聊指令验收；这不是全命令覆盖证明，也不能替代新安装环境的逐 Bot 验收。
PNG 卡片由官方 QQ 图片工具投递，最终送达仍以协议回执及接收端验收为准。
